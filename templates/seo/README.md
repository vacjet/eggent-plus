# Проект: SEO

Шаблон рабочего места по одному сайту. Ставится скриптом:

```bash
python3 scripts/install-template.py --template seo --project <id> [--data <каталог data экземпляра>]
```

Что появится в `data/projects/<id>/`:

| Путь | Что |
|---|---|
| `project.json` | карточка проекта для панели (имя, описание, режим памяти) |
| `AGENTS.md`, `context.md`, `memory.md` | правила, контекст и память проекта |
| `check.sh` | проверка: папки, имена отчётов, отсутствие токенов, ссылки на данные |
| `data/external/` | срезы внешних источников (сайт, Вебмастер, Метрика) |
| `reports/` | отчёты по датам: `ГГГГ-ММ-ДД-тема.md` |
| `notes/` | рабочие заметки |
| `skills/` | установленный специалист (`seo`) и скилл `external-sources` |

Проверка шаблона (формат, установка в пустой каталог, что `check.sh` умеет падать):

```bash
python3 scripts/check-templates.py --self-test
python3 scripts/check-templates.py
```

Плейсхолдер `{{site}}` заменяется значением из `template.json` (`variables.site`) — и только
примером домена: настоящий адрес в публичный репозиторий не попадает (решение 41).
