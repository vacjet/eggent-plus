# Этап 7 — удобство

Дата: 14.11.2026. Основание: `docs/roadmap.md` (этап 7), границы — `docs/boundaries.md`.

## Задача этапа

Сборка уже отвечает, проверяет результат и не даёт себя обмануть чужой строкой в письме. Осталось
сделать её удобной в ежедневной работе: темы, выгрузка разговоров, понятная диагностика, когда что-то
упало, и видимость того, из чего складывается расход контекста.

Это последний этап дорожной карты, и он сознательно маленький: ничего из «вне объёма»
(конструктор приложений, мультипользовательность, CRM) сюда не заезжает.

## Границы

1. **Макет не трогаем.** Тема — файл, экспорт — файл, диагностика — раздел в настройках.
2. **Патч — последнее средство.** Сначала то, что даёт файл в `data/`; ядро правим только для
   кнопок и для того, что без ядра не читается.
3. **Проверка умеет падать.** У каждого пункта — негативный кейс.
4. **Ничего не удаляем.** Экспорт ничего не чистит, тема не переписывает настройки молча.

## Шаги

| Шаг | Что | Ядро | Состояние |
|---|---|---|---|
| 7.1 | Темы: три встроенные + своя из файла в `data/themes/` | нет, если тема — CSS-переменные; иначе маленький патч точки входа | не начато |
| 7.2 | Экспорт чатов в md/json (один чат и проект целиком) | нет: `GET /api/chat/history` уже отдаёт чат | не начато |
| 7.3 | Диагностика «где упало»: сборка, модель, MCP, расписания, версия шрифтов и путей | скорее нет: `/api/health` + `build-info` + журналы | не начато |
| 7.4 | Расход контекста по категориям (контекст проекта, скиллы, история, вложения) | да, если считать по частям промпта | не начато |

Порядок по цене и пользе: 7.2 и 7.3 без патча, 7.1 — если тема окажется файлом (проверить по коду
до работы, как это было с 6.3), 7.4 — последним, потому что требует разбора промпта на части.

## Приёмка этапа

| Требование | Чем закрывается |
|---|---|
| тема ставится файлом, без движка тем и маркетплейса | 7.1 |
| разговор можно вынести из Eggent | 7.2: md и json, без потери вложений в списке |
| по экрану понятно, где упало | 7.3: одна страница «что сейчас работает и что нет» |
| расход контекста виден по частям | 7.4 |

## Чего здесь нет

- Маркетплейса тем и экспорта в «красивые» форматы (docx/PDF) — это документы, не чаты.
- Сбора телеметрии наружу: диагностика остаётся в воркспейсе.
