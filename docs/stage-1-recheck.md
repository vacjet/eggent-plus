# Этап 1 против v0.8.0: что уже сделано апстримом

Проверено 13.11.2026 на чистом клоне `v0.8.0` (`/tmp/fresh`). Дорожная карта писалась 12.11 по
живому экземпляру и частично устарела: два пункта этапа 1 закрыты в самом upstream, один требует
другой формулировки, три остаются открытыми.

| Пункт плана | Что в v0.8.0 | Вывод |
|---|---|---|
| `kb_search` в обычном чате | `src/app/api/knowledge/route.ts` отвечает `410 Gone`: «RAG/knowledge ingestion has been removed». Индекса `.kb` и инструмента поиска в коде нет | **Пункт устарел.** Нужна новая формулировка: поиск по файлам проекта (grep/индекс) как инструмент, а не возврат RAG |
| Скриптовые расписания без модели | `src/lib/pi/schedule-host.ts`: задание хранит `prompt`, запуск идёт ходом модели. Режима «выполнить команду без модели» не было | **Сделано 13.11.2026** — патч `0003-script-schedules` |
| Зависание карточки вопроса | `interaction-types.ts` знает `timeoutMs`, `interaction-ui-context.ts` прокидывает `dialogOptions?.timeout`, но значения по умолчанию нет | **Под вопросом:** механизм есть, дефолт не задан — нужен воспроизводимый тест, а не патч вслепую |
| Вложения в чат > 10 МБ | `MAX_UPLOAD_BYTES = 100 MB`, `middlewareClientMaxBodySize: "100mb"`; `npm run -s test:upload-limit` → 14/14 | **Закрыто апстримом** |
| Картинки через async-API | поиска по `imageJob`/`poll` в `src/lib` не было: генерация синхронная | **Сделано 13.11.2026** — патч `0002-image-async` |
| Расход по чату и проекту | учёт `usage` в ходе был, в интерфейсе — только баланс провайдера | **Чаты и проект сделаны 13.11.2026** (`0004-chat-usage`, `0005-project-usage`); мягкий порог — следующий шаг |

## Что из этого следует

1. Из шести пунктов этапа 1 остаются три: скриптовые расписания, async-картинки, расход по чату.
2. Пункт про `kb_search` надо переписать в задачу «поиск по файлам проекта», прежде чем что-то
   делать: возвращать удалённый RAG — это новый слой хранения, а он за границей (`docs/boundaries.md`).
3. Пункт про зависание карточки требует сначала воспроизведения: без него правка будет угадыванием.

## Что из этого сделано

Все три пункта закрыты 13.11.2026 отдельными патчами: `0003-script-schedules`, `0002-image-async`,
`0004-chat-usage` и `0005-project-usage`. Остался мягкий порог расхода — см. `docs/handoff.md`.
