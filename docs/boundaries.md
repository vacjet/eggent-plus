# Границы: что мы не делаем

Решение 12.11.2026. Список закрыт, пока не появится конкретная задача человека.

| Не делаем | Во что это превратило бы Eggent | Чем закрываем вместо |
|---|---|---|
| CRM, учётные системы, запись в них | вторая CRM / интеграционная платформа | чтение по запросу через скилл/MCP, когда появится задача |
| Почтовый клиент (контакты, метки, поиск по ящику, ответы из интерфейса) | почтовый клиент | список писем + открыть письмо + отправленные агента |
| Бизнес-модули как подсистема с собственными представлениями | конструктор приложений | пакет специалиста (промпты + скиллы + файлы) |
| Справочники как отдельное хранилище с типами и связями | мини-ERP | файлы CSV/JSON в проекте + индекс `.kb` |
| Фреймворк подключений (обновление токенов, лимиты, вебхуки, модели объектов) | iPaaS | два-три конкретных источника через скилл/MCP |
| Лимиты расходов с блокировкой | биллинг | счётчики + мягкий порог с предупреждением |
| «История задания» как отдельная сущность | таск-трекер | поля карточки доски + журнал запусков |
| Fork разговора | — | не нужен: путает, история и версии файлов достаточны |
| Переделка макета на четыре области | редизайн продукта | текущая раскладка, новое встраивается в существующие области |
| Мультипользовательность, роли, LDAP, OIDC | корпоративная платформа | один воркспейс; много людей — Eggent Enterprise |
| Генеративный React-UI из ответа модели | отдельный продукт | HTML-страницы с превью, которые уже есть |
| Sandbox-интерпретатор кода, изолированные dev-среды | платформа разработки | терминал проекта, отдельные LXC, `git worktree` |
| Возобновление хода с контрольной точки после рестарта | сложная подсистема | ход помечается прерванным, задача запускается заново |
| OpenTelemetry, Langfuse, Trace Viewer | наблюдаемость корпоративного уровня | журнал запусков + понятная ошибка в карточке |
| Темы как движок и каталог | тема-маркетплейс | три встроенные темы + свой CSS-файл в `data/` |

Правило на будущее: если предложение требует **новой подсистемы хранения, нового слоя интеграций
или собственного представления данных**, это выход за границу. Сначала спрашиваем, нельзя ли решить
скиллом, конфигом или файлом в проекте.
