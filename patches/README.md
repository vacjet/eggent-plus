# Патчи

Патчи применяются `scripts/apply-patches.sh` строго по порядку имён файлов.

Правила:

1. Имя: `000N-<тема>.patch` через дефис, латиницей, тема — одна.
2. Один патч — одна логическая правка. Русская локаль, `kb_search` в чате и скриптовые расписания
   не смешиваются в одном файле: иначе откат одной вещи тянет за собой другие.
3. Патч обязан накладываться на **чистый тег upstream**: проверка `./scripts/apply-patches.sh --check`
   на свежем клоне. Если патч требует другого патча — это нормально, порядок задаёт имя.
4. Ничего из `data/`, `node_modules/`, ключей и секретов в патчи не попадает.
5. Добавили патч — добавили строку в `TOUCHED.md` и строку в CHANGELOG.

Пустой каталог допустим только на старте: скрипт в этом случае вернёт код 2 и это не провал CI,
а явный сигнал «патчей ещё нет».
