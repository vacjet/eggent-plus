Когда: нужно узнать, что отдаёт сайт (sitemap, 404, редиректы) или что показывают Метрика,
Вебмастер и Директ — для отчёта, гипотезы или регулярной проверки по расписанию.

```
python3 site_audit.py --site https://example.ru --out /app/data/external
python3 yandex_read.py --source all --token-file /app/data/secrets/yandex.env --out /app/data/external
python3 yandex_read.py --source metrika --counter 12345678 --months 12
python3 yandex_read.py --status --out /app/data/external
```

Что где лежит (под `--out`, по умолчанию `external/`):

| Файл | Что |
|---|---|
| `site/pages.json` | robots, sitemap, страницы: код, конечный адрес, байты; ключ — URL |
| `yandex/metrika.json` | счётчики и визиты по месяцам; ключ — `счётчик\|месяц` |
| `yandex/webmaster.json` | сайты, страницы в поиске, обход, sitemap по данным Вебмастера |
| `yandex/direct.json` | кампании и отчёт по дням; ключ — `дата\|кампания` внутри периода |
| `status.json` | когда обновлялось, что получилось, какие объекты доступны |

Правила:
1. **Только чтение.** В Директе — только `Campaigns.get` и `Reports`; ни одной записи, ставки
   и бюджеты не меняются. Если человек просит изменить кампанию — это отдельная задача с его
   подтверждением, а не этот скилл.
2. **Токены не печатать.** Лежат в файле с правами 600 (`/app/data/secrets/yandex.env`) или
   в окружении: `YANDEX_SEO_TOKEN` (Метрика и Вебмастер), `YANDEX_DIRECT_TOKEN` (Директ).
   В отчёт, чат и журнал попадает только «ошибка авторизации».
3. **Повторный запуск не создаёт дублей.** Записи перезаписываются по ключу, поэтому один и тот же
   день или URL не задвоится.
4. **Коды возврата:** `0` — прочитано, `1` — источник недоступен, `3` — ошибка авторизации
   (токен неверный, просрочен или без прав). Ненулевой код виден в журнале расписания.
5. Сломанный или просроченный токен не «чинится» повтором: сказать человеку, какой источник
   отказал, и что нужно выпустить новый токен.

Как отвечать: сначала вывод (что сломалось / сколько визитов / сколько страниц в поиске),
затем цифры из файлов и дата чтения из `status.json`. Нет данных — так и сказать, а не считать
по памяти.
